# Nova Insurance Assistant

Prototype de chatbot documentaire appliqué à des contrats d'assurance
entièrement synthétiques.

## Principes

1. Sélectionner le corpus applicable avec des filtres exacts.
2. Effectuer la recherche sémantique uniquement dans ce corpus.
3. Répondre seulement lorsque les preuves sont suffisantes.
4. Afficher les sources utilisées.

## Environnement

- Python 3.12.1 avec pyenv
- Poetry pour les dépendances et l'environnement virtuel
- Streamlit pour l'interface
- Pytest pour les tests
- Ruff pour la qualité du code

## Installation

```bash
pyenv local 3.12.1
poetry install
```
